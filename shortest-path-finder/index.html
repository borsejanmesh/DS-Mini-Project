How It Works

Graph

Locations are represented as vertices and connections as weighted edges.

Adjacency List

The graph is stored as an adjacency list: each node keeps a list of its neighbours and the weight of each edge.

Dijkstra

Dijkstra finds the minimum-distance path in a weighted graph with non-negative edge weights by always expanding the closest unvisited node.

Path Reconstruction

The previous-node map records how each node was reached. Following it backwards from the destination gives the final shortest route.
